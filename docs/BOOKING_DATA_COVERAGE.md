# 公开运动场地预约余量核查

核查日期：2026-10-22。

使用 DATA.GOV.HK 官方支持的 `package_list` 取得完整目录（本次 3,831 个数据集），
筛出康文署全部 124 个数据集，逐一使用 `package_show` 核查元数据及资源链接。
`package_search` 返回的是不完整的搜索索引，不作为全量目录。

目前确认有可读取场地预约余量文件的项目为羽毛球、篮球、排球、网球、草地足球，五项均已接入。
完整来源、项目名称、资源地址登记于 `backend/app/data/booking_sources.json`，
后端 `/api/v1/availability/sports` 和前端运动选择器共用该清单。新增项目须先验证文件格式，再更新来源登记。

未将仅提供设施位置的乒乓球、壁球、健身室等数据误认为预约余量。
社区康体活动资料是课程/活动资料；图书馆电脑设施可用情况是另一类资源，均不加入运动场地预约地图。
此结论仅限本次官方目录核查，不代表康体通只能预订五种运动，也不代表未来不会公开更多接口。

官方目录 API 指南：https://data.gov.hk/en/help/ckan-api-development-guide
