## 产品范围

香港运动场所可视化地图：缩放、拖动、运动分类、场所详情、主动定位和 AI 选场。
有公开预约数据的运动可展示可订时段和余量；没有余量数据时显示“余量未知”，不能当成已满。

接口模板：

```text
https://portal.csdi.gov.hk/server/rest/services/common/{dataset_id}/FeatureServer/0/query
```

研究中使用的计数参数：

```text
where=1%3D1&returnCountOnly=true&f=json
```

研究中使用的地图参数：

```text
where=1%3D1&outFields=*&outSR=4326&f=geojson&resultRecordCount=1000
```

图层包含坐标。接入时须检查字段、缺失值、分页和实际可用记录数，不能以 1000 条请求上限判断完整性。
代表点不一定是实际入口。

## 使用约定

- 在线底图按需加载，设施定期同步缓存。
- 浏览器仅在用户点击定位后申请权限，拒绝时仍能探索地图；地区搜索和手动选点列入后续实现。
- 缺失余量、未覆盖、尚未接入、过期或同步失败不能推断为满场。
- 本骨架不把研究快照伪装成在线实时统计。
